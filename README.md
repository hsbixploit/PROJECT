## 📖 Tentang

**UTARA STAY HIGH** adalah kumpulan tools gratis yang bisa langsung dipakai tanpa registrasi. Dibuat dengan HTML, CSS, dan JavaScript vanilla — **tanpa framework**, **tanpa dependency berat**, **tanpa iklan**.

Semua kode ditulis manual, ringan, dan cepat.

---

## ✨ Fitur

| # | Tool | Fungsi |
|---|------|--------|
| 🔗 | **Shortlink** | Bikin link pendek dari URL panjang |
| 🌐 | **Cek IP** | Lihat IP publik + negara + kota |
| 📱 | **QR Code** | Generate QR code dari teks / link |
| 🔐 | **Base64** | Encode & decode teks |
| 📋 | **JSON** | Format & minify JSON |
| 🔑 | **Password** | Generator password kuat |
| 🧮 | **Kalkulator** | Hitung cepat (+, −, ×, ÷) |
| ⚖️ | **BMI** | Cek berat badan ideal |
| 🌡️ | **Suhu** | Konversi C ↔ F ↔ K |
| 🎨 | **Warna** | Random warna hex |
| 🎂 | **Umur** | Hitung umur dari tanggal lahir |
